# Кафе «Чынара» — Next.js + FSD

Онлайн-меню с заказами, выбором стола, админкой блюд и дашбордом персонала.

## Запуск

```bash
npm install
npm run dev
```

| URL | Назначение |
|-----|------------|
| `/` | Меню гостя (сначала выбор столика) |
| `/admin` | Админка блюд (добавить / изменить / скрыть / удалить) |
| `/staff` | Дашборд персонала — входящие заказы |

## Что умеет

### Гость `/`
- При входе — модалка **«Выберите ваш столик»**
- Меню, поиск, категории, корзина
- **Отправить заказ** → уходит на `/staff` с номером стола
- Кнопка **«О ресторане»** — адрес, телефон, Instagram, часы

### Админка `/admin`
- Список всех блюд
- **Добавить** карточку
- **Изменить** (название, цена, описание, фото, категория, бейдж)
- **Скрыть / показать** (не видно в меню гостя)
- **Удалить**

### Персонал `/staff`
- Список заказов в реальном времени (event + poll)
- Toast при новом заказе: «Новый заказ! Столик N»
- Статусы: Новый → Готовится → Готово / Отменён
- Видно: столик, состав, сумма, время

## Данные

Сейчас всё в **localStorage** (работает без бэкенда).  
Чтобы подключить Supabase — замените файлы в `shared/api/`.

## Структура FSD

```
src/
├── app/           page, admin, staff
├── widgets/       sidebar, header, cart-drawer, table-modal, about-modal...
├── features/      cart, order, table-select, category-filter, search
├── entities/      dish, table, order
└── shared/        api, config, ui, styles
```
